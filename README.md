# 🌟 Öne Çıkan Projeler

## 🏢 OmegaERP — Full-Stack Mini ERP

İşletmelerin temel süreçlerini tek sistem üzerinden yönetmek amacıyla geliştirdiğim full-stack Mini ERP uygulamasıdır.

Ürün, kategori, stok, müşteri, tedarikçi, satış, satın alma, cari hesap ve kullanıcı yönetimi modüllerini içerir. JWT tabanlı kimlik doğrulama ve Admin/Employee rol yetkilendirmesi uygulanmıştır.

Geliştirme ortamında SQL Server kullanılan proje, production aşamasında PostgreSQL'e taşınmış; frontend Vercel, backend ve veritabanı Railway üzerinde yayınlanmıştır.

**Teknolojiler:**  
`C#` `ASP.NET Core Web API` `React` `Entity Framework Core` `SQL Server` `PostgreSQL` `JWT` `REST API`

🔗 [GitHub Repository](https://github.com/Firdevs64/OmegaERP)

🌐 [Canlı Demo](https://omega-erp-sigma.vercel.app)

## 📚 DersPusulam — Öğrenci Çalışma ve Planlama Uygulaması

Öğrencilerin derslerini, günlük çalışma hedeflerini ve çalışma sürelerini daha düzenli yönetebilmesi amacıyla Flutter ile geliştirdiğim mobil uygulamadır.

Ders planlama, haftalık program, günlük çalışma hedefleri ve Pomodoro sistemi gibi özellikler üzerinde çalışılmaktadır. Projenin ilerleyen aşamalarında öğretmen, sınıf ve öğrenci yönetimi özelliklerinin eklenmesi planlanmaktadır.

**Teknolojiler:**  
`Flutter` `Dart` `SharedPreferences`

## 🐄 Sürü Takip ve Yönetim Sistemi

Hayvan takibi, aşı ve sağlık süreçleri ile günlük çiftlik görevlerinin dijital ortamda yönetilmesi amacıyla geliştirilen web ve mobil destekli çiftlik yönetim platformudur.

Backend tarafında ASP.NET Core Web API, web tarafında React ve mobil uygulamada React Native kullanılmıştır. Projede görsel analiz ve canlı veri danışmanlığı sağlayan Groq API entegrasyonu da bulunmaktadır.

**Teknolojiler:**  
`C#` `ASP.NET Core Web API` `React` `React Native` `SQL Server` `REST API` `Groq API`

🔗 [Frontend Repository](https://github.com/Firdevs64/suru-yonetimi-takibi-frontend)

🔗 [Backend Repository](https://github.com/Firdevs64/suru-yonetimi-takibi-backend)
